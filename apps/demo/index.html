🍪 Cookie-JA デモ

日本の法令に準拠したクッキー同意バナーライブラリ

🚀 基本的な使用方法

以下のコードを HTML に追加するだけで、APPI 準拠のクッキー同意バナーを表示できます：

<script 
  src="https://cdn.jsdelivr.net/npm/@cookie-ja/widget@latest/dist/cookie-ja.umd.js"
  data-site-id="demo-site-123"
  data-webhook-url="https://your-worker.your-subdomain.workers.dev/collect"
  data-language="ja"
  data-theme="light"
  data-position="bottom"
  defer>
</script>

🔧 設定例

React での使用

import { CookieConsentProvider, CookieBanner, useCookieConsent } from '@cookie-ja/react';

function App() {
  return (
    <CookieConsentProvider 
      config={{
        siteId: 'my-site-123',
        webhookUrl: 'https://my-worker.my-subdomain.workers.dev/collect',
        language: 'ja',
        theme: 'light'
      }}
    >
      <YourApp />
      <CookieBanner />
    </CookieConsentProvider>
  );
}

JavaScript API

// 手動初期化
const cookieJA = window.initCookieJA({
  siteId: 'my-site-123',
  webhookUrl: 'https://my-worker.my-subdomain.workers.dev/collect',
  language: 'ja',
  onAccept: (consent) => {
    console.log('同意されました:', consent);
    // Google Analytics 初期化など
  },
  onReject: (consent) => {
    console.log('拒否されました:', consent);
  }
});

// 状態確認
if (cookieJA.hasConsent()) {
  const consent = cookieJA.getConsent();
  if (consent.categories.analytics) {
    // 分析ツール初期化
  }
}
